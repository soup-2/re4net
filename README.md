# Installation instructions
Download latest release and drag the contents of the archive into the Bin32 directory of your game installation. bio4_multi.exe is provided for multi instance support and has the 4gb patch applied. You should launch the game through this exe if your original bio4.exe is not 4gb patched.
# Hosting & Joining
This will be done through the mod GUI which is opened by the "Insert" key.
To join simply use the steam friends list to join a friend who is in a lobby. The host can also invite you through steam.
To host you can simply select your multiplayer save from the save list in the host menu and select the desired coop save file.
If you do not already have a coop save then to create one, load a singleplayer save file or start a new game then once you are loaded in you can use the checkbox at the top of the host GUI to use the current singleplayer save and then start the lobby.
# Saving
The host can save the multiplayer game by interacting with a typewriter or using the chapter end screen to save. There is also a force save button in the host GUI although you should prefer saving normally. Saved multiplayer data is stored in Bin32/re4net/saved. Do not alter or delete the saved files or you risk losing your save data.
# Mods
Do not run any mods and make sure you are using unaltered files from steam. The logs report if any game files are missing or modified. Mod support will come at a later date.
